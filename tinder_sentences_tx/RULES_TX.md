# Tinder texts: translation rules (sk, cz, de, ua, es, fr, tr, hu)

The And Again app shows a media (picture or short clip) with ONE text; the learner swipes right if the text
is TRUE for the media, left if it is FALSE. Learners are 15-25, levels A1-B2. Every media has four English
texts, written for the media:
- TS = TRUE sentence, FS = FALSE sentence (same structure, wrong on exactly ONE checkable fact: a swapped
  noun, colour, number, place, animal or action a learner sees at a glance),
- TP = TRUE short phrase, FP = FALSE short phrase (2-5 word labels, not sentences; FP looks similar at first
  glance but is clearly wrong for the media after a moment's thought).

Translate all four into the target language.

1. MEANING and JOKE, not wording. Write what a witty native speaker of 20 would write under this picture.
   A literal translation that is not funny (or not natural) is a FAILURE. Idioms, exclamations, slang and
   irony must sound native. If a reference does not travel, use something equally well known in that
   country, but NEVER change what the text claims about the media (who does what, where, colours, numbers,
   objects, animals).
2. The FALSE texts stay wrong on EXACTLY the same fact as in English (the same swapped element), and are
   otherwise parallel to the TRUE texts. FS must not become true by accident; FP must stay a plausible,
   similar-looking but wrong label, never absurd and never wrong only by grammar.
3. The TARGET WORD: the input gives the English word and the app's translation of it (loc). The TRUE
   sentence MUST contain that translation in any natural inflected form (case, plural, conjugation, a
   verb's aspect pair is fine). The TRUE phrase should contain it too. Only if the given translation is
   clearly wrong for this sense, use the right equivalent and add a note.
4. Length: sentences may exceed 60 characters where the language needs it, but keep them as short as the
   English (a short English sentence stays short). Phrases stay 2-5 words, max ~40 characters, lower-case
   start (German nouns keep their capital), no final full stop.
5. GRAMMAR FLAWLESS: agreement, case, gender, articles, aspect, word order, diacritics, capitalisation.
   Sentences start with a capital and end with . ! or ?. Tense follows the English (an action going on
   now = the language's present/progressive form).
6. Typography of the language: Spanish ¡…! ¿…?; French a space before ! ? : ; ; German „…" or plain quotes
   as the English uses quotes for irony (keep the ironic quotes); Ukrainian «…» for ironic quotes;
   Slovak/Czech „…".
7. Register: informal is fine (address a person with the informal you: ty / du / tú / tu / sen / te / ти).
   Mild swearing only where the English has it, at the same strength. NEVER slurs, nothing sexual, nothing
   about bodies or looks, nothing mocking a nationality, religion, race or disability. Pop-culture names
   stay if they are known in the country, else swap for an equally famous local-or-global one.
8. Gender: keep the English subject's gender (he/she); where English is neutral ("someone", "they",
   "the teacher"), choose the form that fits the media or a natural neutral one.
