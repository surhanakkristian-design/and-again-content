- 153, phrases[0]: "in einem Eiskübel kühlen" -> "in einem Eiskübel gekühlt werden" — "kühlen" is transitive; the bottle is being chilled, it does not chill something.
- 157, phrases[0]: "den Kaugummi öffnen" -> "den Kaugummi auspacken" — one does not "öffnen" a chewing gum in German; the clip shows unwrapping.

- 157, answer: "Sie öffnet den Kaugummi." -> "Sie packt den Kaugummi aus." — same verb as the phrase.
- 169, phrases[2]: "neben der Töpferscheibe stehen" -> "in der Nähe der Töpferscheibe stehen" — "near", not "next to".

- 186, phrases[1]: "der Band zurufen" — "zurufen" normally takes an object ("der Band etwas zurufen").
- 168: "eine gerollte Urkunde" — "zusammengerollte" is more usual.
